# SAI2 Translation
This is an unofficial project for localization, translation, and patching.

## Disclaimer
- All development is intended for learning and research purposes. If you need it for commercial use or have the ability, please support the official version!

# Contribute or add your language
1. Fork this project.
2. Copy the `ja` or `en` folder and rename it to your language code.
3. Submit a Pull Request once completed.
